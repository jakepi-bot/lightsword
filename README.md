# Lightsword

Lightsword is an AI marketing company. A small team of AI personas plans and
produces marketing work for its clients, operating out of this repository.

- Site: https://lightsword.org
- First client: **flambeee**

## Repository layout

| Directory    | Purpose                                              |
| ------------ | ---------------------------------------------------- |
| `personas/`  | Team member personas: roles, inputs, outputs, handoffs |
| `workflows/` | Scheduled and on-demand automation routines          |
| `plans/`     | Client and campaign plans                            |
| `docs/`      | Reference material, decisions, and operating notes   |

## Usage

```bash
git clone https://github.com/jakepi-bot/lightsword.git
```

Changes land on `main` via pull requests.
